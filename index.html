1-3電能

電能WJ = 電壓VV × 電荷QC電能WJ = 功率PW × 時間ts電能WJ = 電壓VV 電流IA 時間ts效率η% = 輸出能量W出J / 輸入能量W入J × 100%
能量單位換算成焦耳
1 度（1 kWh）= 1000 瓦特W  × 3600 秒s  = 3.6 × 10⁶ 焦耳J 
1 卡（cal）≈ 4.2 焦耳J （1 焦耳J  ≈ 0.24 卡cal ）
1 電子伏特（eV）= 1.602 × 10⁻¹⁹ 焦耳J 
  • 能量守恆：能量不會消失，只會轉換形式；損失的部分大多變成熱。
  • 效率 η 一定 小於 100%。
例題

1000 W 電熱器用 3 小時：電能WJ = 功率PW × 時間ts = 1 kW × 3 h = 3 度 = 3 × 3.6×10⁶ = 1.08×10⁷ J。

1-5電壓

電壓VV = 電能WJ / 電荷QC1 伏特V  = 1 焦耳J  / 庫侖C a對b電壓VabV = a點電位VaV − b點電位VbV
名詞意義
電位某點相對於參考點（接地 = 0 V）的電壓
電位差（電壓）兩點電位的差，移動 1 C 電荷所做的功
電動勢 E電源內部把其他能量轉成電能、推動電荷的能力（電池、發電機）
電壓降電流流過負載（電阻）後電位降低
  • a對b電壓VabV = −b對a電壓VbaV；Vab 為正代表 a 點電位比 b 點高。
  • 電壓表要與待測元件並聯。
例題

將 5 C 電荷由 b 移到 a 做功 20 J，則 電壓VabV = 電能WJ / 電荷QC = 20 / 5 = 4 V。

1-6電流

電流IA = 電荷QC / 時間ts1 安培A  = 1 庫侖C  / 秒s 
比較電子流傳統電流（課本用這個）
方向負極 → 正極正極 → 負極（高電位 → 低電位）
關係兩者方向相反
  • 電流表要與待測元件串聯。
  • 導體中移動的是自由電子；電解液中是正、負離子。
例題

2 秒內通過 1.25×10¹⁹ 個電子：電荷QC = 1.25×10¹⁹ ÷ 6.25×10¹⁸ = 2 C，電流IA = 電荷QC / 時間ts = 2 / 2 = 1 A。

1-7電功率

功率PW = 電能WJ / 時間ts功率PW = 電壓VV 電流IA功率PW = 電流IA² 電阻RΩ功率PW = 電壓VV² / 電阻RΩ1 馬力hp  = 746 瓦特W 
題目給的量選哪條公式
電壓 V 和電流 I功率PW = 電壓VV 電流IA
電流 I 和電阻 R（串聯常用）功率PW = 電流IA² 電阻RΩ
電壓 V 和電阻 R（並聯常用）功率PW = 電壓VV² / 電阻RΩ
電能 W 和時間 t功率PW = 電能WJ / 時間ts
  • 電費：度數 = 功率(kW)PkW × 時間(h)th × 天數，再乘每度電價。
  • 燈泡標示「110 V、100 W」：電阻RΩ = 電壓VV² / 功率PW = 110² / 100 = 121 Ω（電阻固定）。
陷阱

同一顆燈泡電壓變成一半，功率變成 1/4（因為 功率PW = 電壓VV² / 電阻RΩ，電阻 R 不變）。計算電費時瓦特要先換成 kW。

2-3歐姆定律

電壓VV = 電流IA 電阻RΩ電流IA = 電壓VV / 電阻RΩ電阻RΩ = 電壓VV / 電流IA電流IA = 電導GS 電壓VV
  • 溫度不變時，導體兩端電壓與電流成正比。
  • 線性電阻的 V–I 圖是一條過原點的直線。橫軸 V、縱軸 I 時，斜率 = 1 / 電阻 R = 電導 G；斜率越大，電阻越小。
  • 非線性元件（燈泡燈絲、二極體）不是直線。
陷阱

看清楚圖的座標軸：橫軸是電流 I、縱軸是電壓 V 時，斜率才是電阻 R。

例題

10 Ω 電阻接 20 V：電流IA = 電壓VV / 電阻RΩ = 20 / 10 = 2 A，功率PW = 電壓VV 電流IA = 20 × 2 = 40 W。

2-4電阻溫度係數

新電阻R₂Ω = 原電阻R₁Ω [1 + t₁時溫度係數α₁1/°C (新溫度t₂°C − 原溫度t₁°C)]新電阻R₂Ω / 原電阻R₁Ω = (推算絕對溫度T°C + 新溫度t₂°C) / (推算絕對溫度T°C + 原溫度t₁°C)t°C時溫度係數αₜ1/°C = 1 / (推算絕對溫度T°C + 溫度t°C)
類型溫度升高時材料
正溫度係數（α > 0）電阻變大金屬導體（銅、鋁）、PTC
負溫度係數（α < 0）電阻變小半導體、碳、絕緣體、電解液、NTC
零溫度係數（α ≈ 0）幾乎不變錳銅、康銅（做標準電阻）
材料推算絕對溫度 T常用 α
銅234.5 °C（即 −234.5 °C 時 R = 0）0°C溫度係數α₀1/°C ≈ 0.00427、20°C溫度係數α₂₀1/°C ≈ 0.00393
鋁236 °C20°C溫度係數α₂₀1/°C ≈ 0.0039
陷阱

溫度係數 α 會隨參考溫度改變：α₁ 必須是 原溫度 t₁ 時的係數。溫度越高，α 越小。

例題

銅線 20 °C 時 10 Ω，求 70 °C 電阻：新電阻R₂Ω = 原電阻R₁Ω × (推算溫度T°C + 新溫度t₂°C) / (推算溫度T°C + 原溫度t₁°C) = 10 × (234.5 + 70) / (234.5 + 20) ≈ 11.96 Ω。
