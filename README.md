# 基本電學上學期 重點整理（高職一年級）

Basic Electricity study notes for Taiwanese vocational high school students (高職 / 技高).

**線上閱讀：https://basic-electricity.vercel.app**

## 內容

依課本目錄整理，第 1 章到第 6 章與附錄：

| 章 | 單元 |
|---|---|
| 1 電學概論 | 電的特性、單位、電能、電荷、電壓、電流、電功率 |
| 2 電阻 | 電阻及電導、各種電阻器（色碼）、歐姆定律、電阻溫度係數、焦耳定律 |
| 3 串並聯電路 | 串聯、並聯、KVL、KCL、電壓源及電流源、串並聯電路、惠斯登電橋、Y-Δ 互換 |
| 4 直流網路分析 | 節點電壓法、迴路電流法、重疊、戴維寧、諾頓、等效電路互換、最大功率轉移 |
| 5 電容及靜電 | 電容器、電容量、電場及電位 |
| 6 電感及電磁 | 磁的特性、電感器、電感量、電磁效應、電磁感應 |

## 特色

- 每一節從「先搞懂」開始，用白話與比喻說明概念，再整理公式、推導、解題步驟與例題，不看課本也能讀懂
- 每個公式：**上面是中文名稱、下面是單位**，除法寫成上下分數，方便背誦
- 附 11 張電路圖與示意圖
- 最後有「公式總表」，標示每條公式出自哪一個單元
- 淺色／深色模式切換；在空白背景連點兩下，回到最上面的目錄
- 手機、平板、電腦都能閱讀
